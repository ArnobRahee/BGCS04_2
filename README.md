# BGCS04 · Rally, the away-game team travel planner

Hackathon group 04. The app lives in [`travel-planner/`](travel-planner/README.md): setup, how it
works, the demo script and known limitations are in that README.

- Live demo: https://bgcs04-team-travel.onrender.com
- Run locally: `cd travel-planner && pip install -r requirements.txt && python app.py && open http://localhost:5000/`

- Tests: `cd travel-planner && pip install -r requirements-dev.txt && python -m pytest -q tests`
